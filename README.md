# 生年之窗

今天还活着的人，最早出生于哪一年？

这个页面用世界最长寿在世者的年龄、中国和世界的人均预期寿命，画出“仍有人在世”的出生年份窗口，并让它逐年向右移动。输入出生日期后，页面会算出你已经走过的周数和天数，以及距离几个参照年龄还剩多少。

在线查看：https://huzhe01.github.io/lifespan/

- 页面是单个静态文件 `index.html`，不需要构建。
- 年龄和周数按打开页面当天的日期计算。
- 最长寿在世者名单写在页面脚本的 `PEOPLE_RAW` 里，数据更新于 2026 年 11 月 2 日；名单变化后需要手动更新。
- 数据来源列在页面底部。
